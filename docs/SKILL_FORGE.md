# Skill forge

Vishnu-2 can add a skill when the built-in tools do not cover a goal. The forge writes a small Python file, rejects imports and security access, runs the skill in a subprocess, and deletes it if the test fails.

This is original Vishnu-2 code. It is not a copy of any other assistant. Stop still blocks tool actions, and a forged skill cannot clear Stop or read the vault.
